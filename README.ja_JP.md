# XJJ Housekeeper（Version 1.0.0 倩影の居）

[English](README.en_US.md) | 日本語 | [ไทย](README.th_TH.md) | [繁體中文](README.zh_TW.md) | [简体中文](README.md)

「ローカルの番号動画ライブラリ」を管理するデスクトップアプリです。複数のディスクや深いフォルダに散らばった動画を“ローカル索引”として整理し、重複ダウンロードを防ぎ、実ファイルの場所をすぐに特定できます（外付けドライブが未マウントでも最後に確認した場所を把握できます）。

## 解決する課題

- 作品数が多く、ディスクも多く、フォルダ階層が深い
- ファイル名が不統一（前後の文字列や透かしなど）で同じ作品を再ダウンロードしがち
- 外付けドライブの抜き差しが多く、未マウントでも「持っているか」「どこにあるか」を知りたい
- タグ付け、好みの記録、検索、再生をひとつの画面で行いたい

## 「ローカル索引」を選ぶ理由

- 完全オフライン：メタデータや好み情報はPC内に保存
- ドライブに強い：未マウントでも最後の場所（パス）を把握
- 重複防止：ファイル名が変わっても「既にある」を判定しやすい
- 高速検索：番号、女優、タグであいまい検索

## 対象ユーザー

- 大量のローカル動画が複数ディスク/複数フォルダに分散している方
- オンラインサービスではなくローカルDBで管理したい方
- 作品情報のデータを自分で用意できる方（インポートは可能、スクレイピングは提供しません）

## 主な機能

### 1) 検索・閲覧（Query）

- あいまい検索：番号 / 女優名 / タグ
- 表示：ページング、ソート、表示列のカスタマイズ
- ダブルクリック操作：
  - パス列：ファイルマネージャで表示
  - それ以外：既定プレイヤーまたは指定プレイヤーで再生
- 好み：like / dislike / deleted

### 2) ライブラリ整備（Maintain）

- スキャン登録：単一フォルダまたは親フォルダ（配下も含む）を一括取り込み
- フォルダ清掃：`ABC-123.mp4` 形式へ正規化（ルールは設定で調整）
- スマートマージ：同じフォルダを何度でもスキャン可能
  - 新規ファイルは索引に追加
  - 移動済みファイルは再スキャン時に認識してパスを更新（重複登録を防止）
  - ドライブ接続後に再スキャンして最新状態へ

### 3) 問題のある動画の発見（ファイル削除はしない）

- 破損/異常：再生できない可能性のある動画を一覧
- 重複：同一番号に複数レコードがあるものを一覧
- 重要：本アプリの「削除」はDBレコードの削除/マークのみで、実ファイルは削除しません。削除はファイルマネージャで行ってください

### 4) 作品情報（女優・公開日・タイトル）

- 目的：番号に対して女優や公開日などを補完し、検索や集計を強化
- 法的リスク低減のため、情報取得のスクレイピング機能は提供しません。用意したデータをインポートしてください
- インポート/エクスポート形式：UTF-8テキスト（BOM可）、`|` 区切り、ヘッダ固定：

```
actress_name|video_code|release_date|title
```

例：

```
actress_name|video_code|release_date|title
サンプル女優|ABC-123|2024-01-02|サンプルタイトル
サンプル女優|DEF-456||任意
```

### 5) 設定・バックアップ

- 設定：
  - アプリ名
  - UI言語（アプリ内で切替）
  - ページサイズ、表示列
  - タグ管理
  - リネームルール管理（ファイル名正規化）
- バックアップ：
  - 単一JSONにエクスポート（DB + 設定 + ルール）
  - インポートで復元
  - 初期化（データ/設定のリセット）

## 対応形式とフィルタ

- 対応拡張子：`.mp4 .mkv .mov`
- 取り込み時は極小ファイル（10KB未満）をスキップ
- ファイル名正規化は `.mp4/.mkv/.mov` を対象にし、既定で100MB未満はスキップ（調整可能）

## クイックスタート（デスクトップ）

### 方法 A：ソースから実行（カスタマイズ向け）

要件：

- Python 3.10+
- Poetry
- 推奨：FFmpeg（`ffprobe`。長さ/解像度/コーデック取得に使用）

依存関係のインストール（プロジェクトルート）：

```bash
poetry install
```

起動：

- macOS：`startup/XJJ-Desktop.command` をダブルクリック
- Windows：`startup/XJJ-Desktop.bat` をダブルクリック
- 直接実行：

```bash
python -m ui.tkinter.app
```

初回の流れ（推奨）：

1. 設定/バックアップで「初期化」を実行
2. Maintainで動画フォルダを選び「スキャン/取り込み」
3. Queryで番号/女優/タグ検索し、ダブルクリックで再生/表示

既定の保存先：

- ソースから実行：プロジェクトルート配下の `output/` に保存
  - DB：`output/video_info_collector/database/video_database.db`
  - UI設定：`output/video_info_collector/settings.json`
  - リネームルール：`output/video_info_collector/conf/rename_rules.yaml`
- パッケージ版：ユーザーデータ領域に保存（アップデート/アンインストールでもデータが残りやすい）
  - macOS：`~/Library/Application Support/倩影の居/output/...`
  - Windows：`%APPDATA%\\倩影の居\\output\\...`

## 使い方ガイド（シーン別）

ここでは機能一覧の繰り返しではなく、「何をしたいか」から逆算した手順をまとめます。

### 0) 事前準備：おすすめはフォルダを2種類に分ける

- 長期保管フォルダ（本棚/メインライブラリ）：複数ディスク・複数フォルダでもOK。分類は好みで。
- 一時処理フォルダ（受信箱/作業場）：新規ダウンロードや乱れたファイル名のものをまずここへ。正規化して確認後にメインへ移動。

こうしておくと、リネーム/清掃が安全になり（本棚を壊しにくい）、DBに記録されるパスも安定します。

### 1) Query：番号/タグ/女優ですぐ探したい

目的：フォルダ探索をやめて、実ファイルの場所に一発で飛ぶ。

- Query でキーワード検索：
  - 番号（推奨）：`ABC-123`
  - タグ：`アクション`、`2024` など
  - 女優名：作品情報をインポートしていると当たりやすい
- 結果表示後：
  - パス列をダブルクリック：ファイルマネージャで表示
  - その他の列をダブルクリック：既定/指定プレイヤーで再生
- 外付けドライブ未マウント時：
  - 最後に確認したパスは検索できます
  - 再生/表示はドライブ接続後に行ってください
- 好みの使い分け（例）：
  - `like / dislike`：フィルタ用の好みラベル
  - `deleted`：DB上では削除扱い（実ファイルは削除しません）

### 2) Maintain：取り込みと再スキャンを安全に回す

目的：複数ディスクの動画をローカル索引化し、移動してもパス更新できるようにする。

#### シーンA：すでにカテゴリ別の多階層フォルダで、ファイル名も概ね番号形式

例：

- `/Volumes/Disk-1/folder/アクション/ABC-123.mp4`
- `/Volumes/Disk-1/folder/ドラマ/DEF-456.mp4`
- `/Volumes/Disk-1/folder/ドラマ/2024/XYZ-999.mp4`

おすすめ手順：

1. Maintain で取り込みたい「トップのフォルダ」（例：`/Volumes/Disk-1/folder`）を選び、スキャン/取り込みを実行。
2. スキャン後、フォルダ構造から自動タグ付けされます：
   - ルート直下の「第一階層のサブフォルダ名」をタグとして付与（例：`アクション`、`ドラマ`）
   - 葉フォルダ（直下に動画があるフォルダ）を直接スキャンした場合は、そのフォルダ名をタグに
3. 注意：自動生成タグは動画レコードに紐づくため検索には使えますが、設定で管理している「タグ一覧」には自動追加されません。

#### シーンB：新規ダウンロードのファイル名が乱れているので、先に清掃してから取り込みたい（推奨）

例：

- `example.com_abc-123_1080p.mp4`
- `【透かし】ABC-123(uncensored).mp4`

おすすめフロー：

1. まず一時処理フォルダへ入れる。
2. 一時処理フォルダでファイル名正規化を実行し、結果を確認する（誤判定による誤リネーム防止）。
   - CLI：`python -m tools.filename_formatter <一時フォルダ>`
3. 確認後、メインライブラリ（カテゴリ別の保管先）へ移動する。
4. Maintain でメインライブラリをスキャン/取り込みする。

#### 再スキャンと移動（搬家）

- 同じフォルダは何度でもスキャン可能：新規は追加、移動済みは検知してパス更新。
- `missing` は「今回のスキャン範囲」に対してのみ評価されます。別フォルダのデータが誤って missing になりにくい設計です。

### 3) 問題動画：異常/重複を見つけて自分で判断する

目的：問題候補を一覧化し、削除判断はユーザー側で行う（アプリが勝手にファイル削除しない）。

- 破損/異常：
  - 長さ等のメタデータが取れない（`ffprobe` 未導入、またはファイル破損の可能性）
  - FFmpeg（`ffprobe` 含む）を導入して再スキャン推奨
- 重複：
  - 同一 `video_code` のレコードが複数ある状態
  - サイズ/解像度/ビットレート等を見て残すものを決める
  - DBレコード削除や `deleted` マークは可能。実ファイル削除はファイルマネージャで行ってください

### 4) 作品情報のインポート：女優/公開日/タイトルを補完する

目的：ローカル索引に対し、女優・公開日・タイトル等を付与して検索/統計を強化。

おすすめ（デスクトップUI）：

1. Maintain の「作品情報」から Import を実行。
2. UTF-8（BOM可）のテキストで、ヘッダは固定：

```
actress_name|video_code|release_date|title
```

3. インポート後、Query で女優名検索が当たりやすくなります（video_code の一致が前提）。

### 5) DBファイルの扱い：バックアップ/移行と readonly 注意

目的：安全に移行でき、複数ドライブ運用でも困らない状態にする。

- 推奨：DBはローカルの書き込み可能な場所に置く。DB内のパスは外付けドライブ上の動画でも問題ありません。
- DBを readonly の場所に置くと `attempt to write a readonly database` で更新できません。
  - DBをローカルの書き込み可能な場所へ戻してから運用してください。
- バックアップ/移行：
  - 設定/バックアップで単一JSON（DB + 設定 + ルール）をエクスポートし、別環境でインポートするのがおすすめ。
  - DBファイルだけコピーする場合は、UI設定とリネームルールも合わせて移すと体験が揃います。

### 方法 B：パッケージ化して dist から実行

PyInstallerを使用します：

- macOS：`startup/Build-XJJ-Desktop-App.command`
- Windows：`startup/Build-XJJ-Desktop-App.bat`
- ffmpeg/ffprobe を同梱する場合：
  - macOS：`startup/Build-XJJ-Desktop-App-With-FFmpeg.command`
  - Windows：`startup/Build-XJJ-Desktop-App-With-FFmpeg.bat`

成果物は `dist/` に出力されます。

OS：

- macOS（推奨）

- FFmpeg / ffprobe：動画メタデータ取得用（推奨。パッケージ同梱も可）
- ファイル表示や再生はOSの機能に依存します
